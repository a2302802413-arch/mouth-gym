# Mouth Gym

Mouth Gym 是一个本地运行的无 AI 表达训练 Web 应用。通过计时、浏览器录音、中文语音识别和逐句复盘，帮助你把一个场景、产品或知识讲得更清楚。

## 快速开始

1. 确认已安装 Python 3.11+（本机已验证 Python 3.13）。
2. 双击 `start.bat`，或在 PowerShell 中运行：
   ```powershell
   .\start.ps1
   ```
3. 浏览器会自动打开 `http://127.0.0.1:8000`。
4. 推荐使用新版 Chrome 或 Edge。首次练习时允许浏览器访问麦克风。

## 两个练习模式

### 即兴发挥

- 从全部启用的题库中随机抽题，不提供换题。
- 30 秒准备后自动进入表达。
- 每次开始前选择 1、2 或 3 分钟表达时长。
- 适合临时场合发言、描述物品和介绍产品。

### 深度研究

- 可以按分类从资料库随机抽取效应、实验、机器或科技原理，也可以输入自定义主题。
- 使用 10 分钟阅读、搜索网页、整理笔记和自编提纲。
- 时间到后自动进入表达，同样可以选择 1、2 或 3 分钟。
- DuckDuckGo 搜索结果可以一键保存到本地资料库。
- 点击研究页的“ai搜索”，会在应用窗口旁边打开 DeepSeek 侧边小窗。

## 录音和复盘

- 表达时同时保存录音，并使用 Chrome/Edge 内置的 Web Speech API 实时生成中文文字。
- 时间到后自动停止录音和识别。
- 复盘页会按停顿、转折词和内容长度，把相邻 2-4 句话合并成步骤；仍可点击单句定位录音。
- 每个步骤或每句话都可以标记“没讲清楚”并填写原因。
- 按模式提供表达自检表，并支持自由复盘。
- 不生成 AI 分数或点评，所有判断由练习者自己完成。

浏览器语音识别属于浏览器内置能力，部分浏览器可能将语音发送给浏览器厂商处理。Firefox、旧版浏览器或不支持语音识别的环境仍可录音，并可手动补充转写文字。

## 数据说明

- 数据库、录音、题库和资料库均保存在本机 `data/` 目录。
- 不接入 LLM，不需要 API Key，也不会上传练习记录。
- 旧版数据库会自动增量升级；已有会话记录会保留，旧 AI 点评不再展示。
- 应用启动时会清除旧 `data/config.json` 中的 API Key 和 AI 配置。
